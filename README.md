# Food-delivery landing page study

A small frontend study inspired by food-delivery marketplaces. It demonstrates a responsive landing page, an auto-hiding header, search-field interaction states, scroll-based presentation effects, and vanilla JavaScript event handling.

## Scope

This is a learning project, not an affiliated Foodpanda product and not a functional ordering service. Navigation and search suggestions are presentation-only; there is no catalog, authentication, checkout, backend, or API integration.

## Stack

- HTML
- CSS
- Vanilla JavaScript

## Run locally

Open `index.html` in a browser. No build step is required.

## Repository notes

The implementation is intentionally compact. `index.html` defines the page, `style.css` contains the responsive presentation, and `script.js` handles scroll and focus interactions.
